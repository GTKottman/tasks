# Daily Routines

## Weekday Morning Routine

### Before the Shower

* [ ] Wake up
* [ ] Get out of bed
* [ ] Locate a clean towel
* [ ] Get water
* [ ] Pick out clothes
* [ ] Bring everything you need into the bathroom

### Shower + Hygiene

* [ ] Put on the news or music
* [ ] Shave if needed
* [ ] Shower
* [ ] Wash hair
    * [ ] Shampoo
    * [ ] Conditioner
    * [ ] Scrub / wash skin thoroughly
* [ ] Baking soda on tongue
* [ ] Brush teeth
* [ ] Mouthwash
* [ ] Dry off completely
* [ ] Hang Towel
* [ ] Deodorant
* [ ] Cologne
* [ ] Get dressed
* [ ] Do hair
* [ ] Hamper up old clothes

### Breakfast + Meds

* [ ] Make something high in protein and low in sugar
* [ ] Eat
* [ ] Take Dapsone as prescribed
* [ ] Take Lexapro as prescribed
* [ ] Magnesium
* [ ] NAC
* [ ] Zinc
* [ ] Vitamin D
* [ ] Probiotics
* [ ] Fill water bottle

### School Check

* [ ] Check today's class schedule
* [ ] Check for anything due or time-sensitive
* [ ] Pack laptop
* [ ] Pack laptop charger
* [ ] School ID
* [ ] Headphones / earbuds
* [ ] Phone
* [ ] Wallet
* [ ] Keys
* [ ] Sunglasses
* [ ] Drink
* [ ] Final bag check

# Nightly Routine

### Prepare Tomorrow

* [ ] Pick out tomorrow's clothes
* [ ] Set aside anything needed for tomorrow
* [ ] Plug in phone / devices
* [ ] Set alarms if needed

### Reset the Apartment

* [ ] Clean off desk
* [ ] Clean off living room table / surfaces
* [ ] Clean off dining room table
* [ ] Clean off kitchen counter
* [ ] Put away dishes and food
* [ ] Organize bathroom counter
* [ ] Pick everything up off the floor
* [ ] Put misplaced things back where they belong
* [ ] Throw away all trash

### Shower + Night Hygiene

* [ ] Shower
* [ ] Wash body thoroughly
* [ ] Wash hair if needed
* [ ] Dry off
* [ ] Put on clean sleep clothes
* [ ] Brush teeth
* [ ] Mouthwash
* [ ] Face / skincare
* [ ] Use bathroom

### Bed Setup

* [ ] Get water
* [ ] Get face mask
* [ ] Get nighttime earbuds
* [ ] Plug in phone / devices if not already charging
* [ ] Confirm alarms are set
* [ ] Turn off all lights
* [ ] Final quick room check
* [ ] Get into bed
